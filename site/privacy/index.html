Privacy

How your RAW file stays local

Effective 5 September 2026

Chosen files

The browser reads a file only after you choose it. The check does not upload its bytes, name, metadata, preview, or result.

Demo data

The demo uses a synthetic Sony sample. It uses a separate temporary browser namespace and never reads your chosen files.

Storage

The normal checker stores no accounts, reports, or chosen files. The demo keeps only its temporary mode label until you leave it.

Offline cache

A service worker caches public site files for offline use. It does not cache your chosen RAW file or result.

Third parties

The demo makes same-origin requests and sets no cookies.

Questions

Open a privacy issue in the public GitHub project repository.
