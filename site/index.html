CLI / Full check

Check a shoot folder with the CLI

The CLI checks folders, extracts previews, and prints a JSON report for scripts.

LOCAL TERMINAL
$ raw-fit-check demo

# Check a representative folder
$ raw-fit-check check ~/Pictures/sample \
    --editor darktable --editor-version 4.8.1

# Save previews and JSON
$ raw-fit-check check sample.NEF --preview-dir ./previews --json

Exit 0usable

Exit 1invalid input

Exit 2preview-only

Exit 3unsupported

Limits

What this check does not do

It leaves your RAW file unchanged.

It does not recommend hardware.

It does not replace testing a real edit and export.

It does not upload your selected file.
